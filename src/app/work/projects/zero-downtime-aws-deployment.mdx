## Infrastructure Blueprint

Deploying production web workloads in emerging market environments requires resilience, deterministic caching, and isolation between compute and media assets.

### Architecture Topology

- **Web Ingress & SSL Termination:** Nginx reverse proxy configured with HTTP/2, brotli compression, and rate-limiting zones to safeguard internal endpoints.
- **Application Runtime:** Gunicorn WSGI processes managed via systemd unit files with graceful reload signals (`HUP`) ensuring zero-downtime during codebase migrations.
- **Media & Static Asset Offloading:** AWS S3 buckets integrated with strict CORS policies, offloading 100% of image rendering bandwidth from EC2 compute instances.
- **Host Hardening:** Ubuntu Linux host security featuring UFW firewall restrictions, automated TLS renewal via Certbot, and swap space tuning for memory resilience during peak surges.
